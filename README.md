# 🚗 DriveGuard AI

Real-Time Driver Fatigue Detection and Safety Monitoring System

## Overview

DriveGuard AI is an AI-powered driver monitoring system that detects driver drowsiness and fatigue in real time using computer vision and facial landmark analysis.

The system continuously monitors eye closure and yawning patterns, generates instant alerts, tracks driver status, logs trip analytics, and sends emergency notifications with location details through Telegram.

---
